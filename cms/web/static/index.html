Bien utiliser MyCMS

            
MyCMS sert à modifier les textes de votre site sans toucher au code. Vos modifications restent sur cet ordinateur jusqu'à ce que vous les publiiez : le site en ligne ne change qu'au moment de la publication.


            
À chaque fois, dans cet ordre

            
    
                
  1. Récupérer : onglet Git, bouton Pull. Vous partez ainsi de la dernière version du site, même si quelqu'un d'autre l'a modifiée entre-temps.
    2. 
                
  2. Modifier : onglet Éditeur. Choisissez une page, cliquez dans un texte et modifiez-le. La barre du haut met en gras, en italique ou ajoute un lien. Terminez par Sauvegarder.
    3. 
                
  3. Vérifier : bouton Aperçu de l'éditeur. La page s'affiche avec vos modifications, avant même de sauvegarder.
    4. 
                
  4. Publier : onglet Git. Choisissez un message qui décrit la modification (ou un message préfait), puis Push. Le site en ligne est mis à jour quelques minutes plus tard.
    5. 
                
  5. Quitter : bouton Quitter en haut à droite. MyCMS montre ce qui n'est pas encore publié et propose trois choix :
                    Revenir à l'état de base (annule tout depuis le dernier commit, même ce qui est sauvegardé),
                    Sauvegarder et quitter (pour reprendre plus tard, sans rien publier) ou
                    Publier sur le site et quitter (envoie les modifications sur GitHub : le site en ligne est mis à jour).
    6. 
            


            
Bon à savoir

            
    
                
  • Sauvegarder n'est pas publier : une modification sauvegardée n'apparaît en ligne qu'après le Push.
    • 
                
  • Tant qu'un changement n'est pas publié sur GitHub, sa fiche porte un marqueur :
    
                    + plus de contenu qu'en ligne,
    
                    − moins de contenu,
    
                    ~ autant de contenu, mais modifié.
    • 
                
  • Seuls les éléments qui ont la classe class="editable" dans le code HTML sont modifiables avec MyCMS. C'est volontaire : le contenu qui n'est pas prévu pour être modifié (mise en page, menus, images, style du site…) ne peut pas l'être par erreur. Pour rendre un nouveau texte modifiable, il faut ajouter cette classe dans le HTML de la page. Ainsi, il est donc d'usage de faire appel à un développeur pour ajouter cette classe.
    • 
                
  • Un texte avec un cadenas est un texte modifiable placé dans un autre : cliquez dessus pour aller à sa propre fiche.
    • 
                
  • Un texte collé arrive sans mise en forme : remettez le gras ou les liens avec la barre d'outils.
    • 
                
  • Certains textes sont en gras à cause du style du site : MyCMS ne permet pas d'en retirer le gras. Plus particulièrement, les textes qui balisées par les balises suivante <strong> ou <b> et <h1> à <h6> sont considérés comme étant en gras.
    • 
                
  • Le plan du site pour les moteurs de recherche (sitemap) se met à jour tout seul à chaque sauvegarde.
